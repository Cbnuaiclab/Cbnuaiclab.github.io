Research Projects

Bridging AI Research with Real-World Impact

Arm Robot for Bin-Picking in Unstructured Environments

The Project aims to develop an intelligent bin-picking system that enables robots to detect, localize, and grasp objects in cluttered, unstructured environments. By combining advanced vision techniques such as instance segmentation, graph-transformer reasoning, depth refinement, shape completion, and 6D pose estimation, the project seeks to overcome challenges like occlusion and sensor noise.

NL2SQL: Natural Language to SQL

This research develops an AI system that converts natural-language questions into accurate SQL queries, removing SQL expertise as a barrier to data access. The research focuses on schema understanding, query validation, hallucination reduction, and automated dataset curation using multiple AI agents. The lab's MRS-Agent submission reached rank #21 on the BIRD benchmark, a large-scale cross-domain Text-to-SQL evaluation, achieving 75.13% execution accuracy on the test set.

Quantum Computing: Large-Scale Optimization

This research explores quantum annealing and hybrid quantum-classical methods for tackling highly complex, large-scale optimization problems that are difficult for conventional computing approaches. The work aims to apply these methods to domain-specific challenges such as synchrotron accelerator scheduling, parameter optimization, resource allocation, and operational control.
